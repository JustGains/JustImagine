# Assets

- `sections/` — the photographs on the Settings panel's "What you can make"
  cards, one scene per section. Generated with JustImagine itself (GPT Image
  2.5 via OpenRouter), 560×840.
- `providers/` — provider marks, used only to identify each provider.
  - `openrouter.svg`, `elevenlabs.svg`, `openai.svg` are from LobeHub Icons
    (https://github.com/lobehub/lobe-icons, MIT). Drawn in `currentColor` and
    shown as a CSS mask, so they take the theme's ink colour.
  - `yunwu.png` and `openlux.png` are the icons each provider's own site serves.

  Each mark is its owner's trademark.
